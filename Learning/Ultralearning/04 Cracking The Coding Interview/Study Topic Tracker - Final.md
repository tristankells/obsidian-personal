# Tips
- Start each review with **retrieval**: solve a problem _before_ checking notes.
- **Space practice** across days and weeks; several short sessions outperform one long cram.
- **Interleave** related topics instead of studying one topic in isolation.
- Embrace **desirable difficulty**—effortful recall builds more durable memory.

# Session Template

## 1. Pre-Study Brain Dump _(retrieval before reading)_
> _Before opening the book or notes, write down everything you already know about today's topic. Even a few bullet points count._

Before I open the book, I know…
## 2. Study Block
> _Do the reading, copy sample problems to Obsidian._

## 3. Session Reflection
>*Do a small review of what you just learned*

**The "Elevator Pitch"** Explain this topic in 2 sentences to a non-coder.
**The "Gotcha"** What is the one thing about this topic that tripped me up and I'd want to review again?
**The Connection** How is this similar to / different from the topic I studied last week? How would I use it in my projects?
**The Generator** _(generative learning)_ Write one novel problem — not from the book — that this technique could solve.
## 4. Error Log | Flash Cards
> _Log every mistake, no matter how small. Identifying the error type helps you fix the right thing.
# Sticky Problems
> _Patterns that have tripped you up more than once. Cross-reference with your Error Log to spot repeating error types._
