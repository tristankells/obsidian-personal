# Prep
- Prime
	- List objectives, materials.
	- Create a master note for links aka "[[Microsoft Applied Skills - Accelerate app development by using GitHub Copilot]]"
- Create a plan
	- What day and time will you study?
# Execution - Short Hand
- 1. Prime; Headers, objectives, assessments
- 2. Thorough; Note keywords + questions
- 3. Review; Mindmap (from memory) + compare
- 4. Tesing; Update anki + create tests.
# Execution
1. Pick a module.
2. Open obsidian on one third of your screen and the learning material take up the other 2/3rds
3. Put on focus mode.
4. Prime / Template
	1. Rewrite the **Learning objectives**
	2. Skim, note keywords (create grouping + think about the shape).
	3. Rewrite **Module assessment** questions.
	4. Start [[Mindmap]] with what you think the key topics will be.
5. Read through unit.
	1. SKIP BELOW FOR AI TOPIC, AS NOT LOTS OF HEAVY TECHNICAL KNOWLEDGE YOU NEED TO REVIEW.
	2. MAKE SURE YOUR NOT COPY PASTING THE WHOLE THING, FOCUS AROUND KEYWORDS OR CONCEPTS.
	3. ==If the material is not suitable for review, you can copy paste to make your own "notes" or "external database" (see [Watch This BEFORE Studying With MINDMAPS - Effective And Ineffective Methods - With Full Demo](https://www.youtube.com/watch?v=7nFsE2qPjic&ab_channel=TomWatchman)).==
	4. An external database should QA and contextual written info. So you you get a question wrong, you have place to search through and review.
	5. ==This is not for re-reading over and over again, but instead revisit if you have got something wrong, want to expand further on something.==
	6. ==If this is centralized, much easier to find the information than say azure microsoft examination web pages.==
	7. If you have to come back to a module, try some active recall practice before continuing to see what your remember.
6. While reading, note keywords, through active recall.
7. While reading, note questions
	-  Some low order and some high order.
8. After reading, update module MindMap, based on keywords.
	- Clean up keywords (review learning objectives). Aim for 20ish.
	- Write mind map based on **topic**, not on *module headers*.
	- Close your eyes and try to recall your mindmap.
	- Does your mind map prompt more questions, what else do you want to know?
	- Make it visual.
9. Repeat steps 3-6 until modules finished.
10. Do assessment.
11. Create Anki cards to review (Ask; What assessment questions did you fail? Where is the mindmap missing detail / relationships? Little details!)
12. Clean up page, with emphasis on questions (+ hidden answers) as the method of review
	- Create quiz / practice tests
13. Follow Up: Book "note" review within 24 hours. Then book another review within a week. *(see spaced repetition)*

# Reminders
- **Don't take detailed "notes"!**
	- Do note keywords + write questions + create mindmaps.
- **Don't highlight!**
	- Do learn to retain then and now.
- **Don't copy paste material!**
	- Do write your "notes" in you own words + recreate diagrams & pictures from memory
- **Don't re-read sources**
	- Illusions of learning
	- Do active recall through quizzing and practice testing.
- **Don't cram.** 
	- Do study little bit every day; 50 mins.
		- Allows for **diffusion** & **spaced repetition**. See [[A Mind For Numbers by Barbara Oakley]]
