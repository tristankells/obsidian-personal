- [ ] **3. Implement Tracing for the "Envelopes" API:**
    - [ ] **Goal:** Add distributed tracing to your "Envelopes" API to monitor performance and dependencies.
    - [ ] Integrate the Application Insights SDK into your API project.
    - [ ] Ensure that requests are being tracked and that you can see them in the Application Insights portal.
    - [ ] If your API calls other services (like a database), verify that these dependencies are also being tracked.
